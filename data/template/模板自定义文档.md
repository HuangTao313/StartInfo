# 开机速览模板自定义文档

## 1.模板的作用

本程序可读取jinja2模板文件(*.j2)来并格式化处理来显示信息，程序提供了丰富的变量可供调用，用户可通过编写模板来自定义各式各样的文案。

## 2.模板文件夹路径

程序安装文件夹\data\template

## 3.导入模板的方式

1.在设置中导入模板。

2.双击打开模板文件，选择导入模板。

3.直接将模板文件放入模版文件夹。



## 4.启用模板的方式

1.在设置导入模板后选择立即启用。

2.在设置-模板列表中启用。

## 7.高级模板
模板支持HTML、CSS和Jinja2语法，可根据需要进行自定义，例如：添加CSS样式、使用HTML标签、使用Jinja2语法进行条件判断等。

## 8.常见问题

### Q：为什么模板中某些变量不显示？
A：请检查是否使用了正确的变量名（如 `solar_term` 而非 `solarterm`）。

### Q：模板中能用条件判断吗？
A：支持 Jinja2 语法，例如：
```jinja2
{% if weather == '晴' %}
☀️ 今天天气很好！
{% endif %}
```

if elif判断
```jinja2
{% if weather == '晴' %}
☀️ 今天阳光真好！
{% elif weather == '雨' %}
🌧️ 记得带伞哦～
{% endif %}
```
