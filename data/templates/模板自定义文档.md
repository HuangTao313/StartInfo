# 开机速览 (StartInfo) 模板自定义文档 

## 一. 模板的作用

本程序可读取 Jinja2 模板文件 (`*.j2`) 并格式化处理来显示信息。程序底层向模板注入了丰富的变量，用户可通过编写模板，结合条件判断语法，自定义各式各样的排版、文案甚至是 HTML 页面。

## 二. 模板文件夹路径

`程序安装文件夹\data\templates`

## 三. 导入模板的方式

1. 在主程序的 **设置** 中导入模板文件。
2. 双击打开模板文件 (`.j2` 或 `.html`)，选择导入模板。
3. 直接将模板文件复制并放入 `template` 文件夹中。

## 四. 启用模板的方式

1. 在设置中导入模板后，点击“立即启用”。
2. 随时在 **设置 -> 个性化 -> 模板** 中选中你想使用的模板并启用。

## 五. 变量列表 (核心)

为了方便模板编写，开机速览(StartInfo) V2.4.0 将变量分为 **“数据展示变量”** 和 **“功能逻辑变量”**。

### 5.2 功能逻辑变量 (组件开关)
这些变量主要返回 `True` 或 `False`，用于结合 `{% if %}` 语法，判断用户在“设置”中是否开启了某项功能，从而实现界面的动态显示与隐藏。

|    对应设置开关     | 变量名 | 作用说明                                |
|:-------------:| :--- |:------------------------------------|
|   **全局总控**    | `is_all_off` | **最高优先级**。如果为 `True`，代表用户关闭了所有信息显示。 |
|   **问候语开关**   | `greeting_switch` | 判断是否显示问候语。                          |
|  **开机次数开关**   | `startup_times_switch`| 判断是否显示今日开机次数。                       |
|  **日期时间开关**   | `datetime_switch` | 判断是否显示日期、时间及年度进度等。                  |
|  **天气模块开关**   | `weather_switch` | 判断是否显示天气卡片相关信息。                     |
|  **历史今天开关**   | `historical_switch` | 判断是否显示历史上的今天。                       |
|  **每日一言开关**   | `words_switch` | 判断是否显示每日一言模块。                       |
| **MC服务器信息开关** | `mc_server_check_switch`| 判断是否启用了 MC 服务器玩家在线信息检测功能。           |
|  **今日人品开关**   | `daily_character_switch` | 判断是否显示今日人品模块。                       |
|   *(系统判断)*    | `is_countdown_available`| 检查当前是否有未过期的、有效的倒数日。                 |
|   *(系统判断)*    | `is_mc_server_online` | 检查 MC 服务器当前是否能连接通。                  |

### 5.3 生日祝福（实验性组件）
在特定日期触发，属于特殊变量：
* `birthday_star`: 寿星名称
* `age`: 生日当天的年龄
* `life_days`: 寿星来到这个世界上的天数

## 六. 编写基础模板与适配开关

在 v2.4.0 中，强烈建议使用 `{% if 开关变量 %}` 将各个模块包裹起来。这样当用户在设置中关闭某项信息时，模板能够自动隐藏对应内容，避免出现空行或无意义的排版。

**基础模版示例 (`default.j2`)：**

```jinja2
{% if is_all_off -%}
★ 开机速览 ★
提示：当前未开启任何信息展示模块。
您可以点击下方“设置”按钮进行配置。
{% else -%}
{# --- 顶部问候 --- #}
{%- if greeting_switch or startup_times_switch -%}
★ {% if greeting_switch %}{{ greeting }}{% endif %}{% if greeting_switch and startup_times_switch %} {% endif %}{% if startup_times_switch %}今天已开机{{ startup_times }}次{% endif %} ★
{{ "\n" }}
{%- endif -%}

{# --- 日期时间 --- #}
{%- if datetime_switch -%}
★今天是{{ date }} 农历{{ lunar_date }} {{ weekday }} 第{{ week_num }}周 第{{ day_num }}天
节假日：{{ holiday }} | 24节气：{{ solar_term }}{% if daily_character_switch %}
🎲今日人品：{{ character }}{% endif %}
今年已过{{ year_progress }} 还剩{{ year_remain }}
{{ time_emoji }}当前时间：{{ time }}
{%- if is_countdown_available -%}
★📅距离【{{ countdown_name }}】还有 {{ countdown_number }}天★
{%- endif %}
{{ "\n" }}
{%- endif -%}

{# --- 天气信息 --- #}
{%- if weather_switch -%}
{{ city_name }}天气：{{ weather_emoji }}{{ weather }} | 🌡{{ temperature }} (体感{{ feels_like }})
★🍃{{ wind_direction }} {{ wind_speed }} | 🌁空气质量：{{ air_quality }}
{{ "\n" }}
{%- endif -%}

{# --- MC服务器状态 (新加入) --- #}
{%- if mc_server_check_switch -%}
★ MC服务器: {{ mc_server_name }} ★
{%- if is_mc_server_online -%}
🌐 状态: 在线 | ⚡ 延迟: {{ mc_server_latency }}ms | 📊 人数: {{ mc_server_current }}/{{ mc_server_max }}
{%- if mc_online_friends %}
✨ 在线好友: {% for name in mc_online_friends %}[{{ name }}]{{ " " if not loop.last }}{% endfor %}
{%- else %}
💤 暂无好友在线
{%- endif %}
{%- else -%}
❌ 服务器目前处于离线状态
{%- endif %}
{{ "\n" }}
{%- endif -%}

{# --- 历史上的今天 --- #}
{%- if historical_switch -%}
★历史上的今天★
{{ historical_date }} {{ historical_event }}
{{ "\n" }}
{%- endif -%}

{# --- 每日一言 --- #}
{%- if words_switch -%}
★每日一言★
{{ words_primary }}
{{ words_secondary }}
{{ "\n" }}
{%- endif -%}
{%- endif -%}
```

## 七. 高级模板 (HTML/CSS)

Jinja2 模板天然支持 HTML 和 CSS 代码。如果你希望构建界面更美观的卡片式速览页面，可以直接在 `.j2` 文件中编写 HTML 代码。

### ⚠️ 核心适配技巧：透明背景
因为 开机速览(StartInfo) 主程序自带了浅色/深色主题切换功能，在编写 HTML 模板的 CSS 样式时，**必须将最底层背景设置为彻底透明** [cite: 1, 2]，否则会出现难看的纯白或纯黑底色，无法融入主程序的弹窗中。

**必须加入以下全局 CSS 代码：**

```html
<style>
    body {
        font-family: "Microsoft YaHei", "Segoe UI", sans-serif;
        margin: 0;
        padding: 0;
        /* 强制透明背景，完美适配深浅色模式 */
        background-color: transparent !important;
    }
</style>
```

> **提示**：除了 `body`，如果你使用了卡片 (`div`)，也尽量使用半透明颜色（如 `rgba(128,128,128,0.2)`）作为边框，并加上 `background: transparent !important;` 以确保高级质感。

## 八. 常见问题

### Q：为什么模板中某些变量不显示？
A：请检查拼写是否与本文档提供的变量名完全一致（如 `solar_term` 不能写成 `solarterm`）。同时也请检查该变量是否被包含在了未开启的 `{% if %}` 开关语句中。

### Q：遇到复杂的数组数据怎么显示？
A：如 `mc_online_friends` 这种列表，需要使用 Jinja2 的 for 循环语法：
```jinja2
{% for name in mc_online_friends %}
    玩家: {{ name }}
{% endfor %}
```

### Q：能使用高级的字典映射逻辑吗？
A：完全可以！比如你想根据不同天气自定义提示语：
```jinja2
{%- set weather_messages = {
    '晴': '☀️ 阳光明媚，适合出门！',
    '雨': '🌧️ 别忘了带伞哦～'
} -%}
{{ weather_messages.get(weather, '🌤️ 保持好心情！') }}
```
